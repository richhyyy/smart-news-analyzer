# Smart News Analyzer

An AI-powered news analysis web app built using Python and Streamlit. It processes RSS feeds and performs NLP-based analysis including sentiment detection, keyword extraction, and automatic summarization.

##  Features

-  RSS Feed Reader (live news fetching)
-  Text summarization (extractive NLP)
-  Sentiment analysis (positive / negative / neutral)
-  Keyword extraction
-  Automatic news categorization
-  Clean dark UI with Streamlit

## Tech Stack

- Python
- Streamlit
- NLTK
- TextBlob
- Feedparser
